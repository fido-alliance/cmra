# Code of Conduct

This project is hosted by the FIDO Alliance and follows the **[FIDO Alliance Code of Conduct](https://fidoalliance.org/code-of-conduct/)**.

## Scope

The FIDO Alliance Code of Conduct applies to everyone who participates in this project, whether or not they are a FIDO Alliance member. This includes contributors, maintainers, and anyone who opens or comments on issues, pull requests, or discussions, as well as any other project space.

Participants are expected to treat one another with respect and professionalism. Harassment, discrimination, and other conduct that would be inappropriate in a professional setting are not tolerated. Discussion should stay focused on the technical content of the project.

## Reporting

To report a concern, email **conduct@fidoalliance.org**. Please include a description of what happened, when and where it happened (links to issues, comments, or commits are helpful), and the names of anyone involved, if known.

Reports are handled under the process described in the FIDO Alliance Code of Conduct.

Project maintainers may also remove, edit, or reject comments, commits, code, issues, and other contributions that do not follow the Code of Conduct.

## Questions

General questions about the Code of Conduct can be sent to help@fidoalliance.org.
